# 00 - Orientação para Agentes

## 1. Funcionamento do Sistema
Este é um sistema multiagente coordenado por humano. Operamos com seis papéis especializados: Arquiteto, Designer de API, Back-end, Front-end, QA e Documentador.

## 2. Ordem de Leitura Obrigatória
Antes de processar qualquer tarefa, o agente deve ler:
1. Este arquivo (`00_orientacao_agentes.md`)
2. O Glossário de Domínio (`09_glossario_dominio.md`)

## 3. Regras Universais de Conduta
1. **Zero Invenção**: Se uma informação não consta nos documentos aprovados, abra uma DIVERGÊNCIA. Nunca presuma.
2. **Validação Humana**: Nenhuma etapa avança sem o "OK" explícito do coordenador (Gabriel).
3. **Fronteira de Escrita**: Respeite rigorosamente os arquivos que seu papel tem permissão para editar.
4. **Justificativa Técnica**: Toda decisão (ex: escolha de um Design Pattern) deve ser acompanhada de uma justificativa de uma frase.
5. **Protocolo de Resposta**: Toda interação deve terminar com o bloco "RESUMO PARA VALIDAÇÃO HUMANA".

## 4. Protocolo de Divergência
Use as tags: `[PENDENTE]`, `[QUESTIONAMENTO]`, `[CONFLITO]`, `[BLOQUEIO]`. Registre imediatamente no `08_log_de_evolucao.md`.
